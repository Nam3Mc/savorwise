Overview:
Recipe Finder with Nutritional Facts
Users search by ingredient or dish name to get a list of recipes. 
When they select one, they see cooking instructions and a nutritional 
breakdown (calories, protein, carbs).

Target Audience:
The Application is targetting the homemakers arround the work and cooking
lovers, that wants to locate recipes by seaching ingredients or specific
recipes, with it nutritional information to eat healty and fun.

Major Functions:

FetchRecipeByIngredient: This function will capture the ingredient 
seach in the API for recipes that contain that ingredient and store 
the data.

SearchByRecipe: The fucntion taht receive a recipe name and request
the recipe from the API and store the data.

RenderRecipes: A function with a template that will render dinamicaly
the recipes as a link to go to the recipe details page.

SearchBar: This function will select the search bar, will verify a check
box for searchin by ingredient or by recipe and call the respective fetch
function and the RenderRecipes to display dinamically when user search

RenderRecipeDetails: This fucntion will use a template to render the 
recipe data, and set a link for each ingrediente setting the ingredient
mame as word for seaching the nutritional data to be render, Including
a list of ingredients.

FetchNutritionalData: A function to fetch the nutritional data of the 
recipe and store the data.

RenderNutritionalFats: Will use a template to render the fetched data
of the recipe.

FetchIngredientFats: This function will fetch the ingredient nutritional
data and store the data.

RenderIngredientFats: This function will call the fecth ingredient fats
when clicking the link genetated by rendering the recipe.

SaveRecipe: A function that will store the recipe that the user wants
to save for later.

Recipe Class: it will receive as parameter, Ingredient or RecipeName
